This comprehensive demo showcases all SurveyJS field types with example data and default values. It is designed for testing the full range of form capabilities including:

  • Text inputs — single line, email, password, URL, phone, number, date, datetime, time, color
  • Multiline content — comments with auto-grow and resize options
  • Choice questions — radio groups, checkboxes, dropdowns, tagboxes
  • Ratings & booleans — numeric ratings, labeled ratings, yes/no toggles
  • Matrix questions — single choice matrix, matrix with dropdowns, dynamic matrices
  • Panels — dynamic panels with add/remove, static grouping panels
  • File uploads — single file, multiple files, images with preview
  • Signatures — signature pad for drawing signatures
  • Special types — expressions, HTML blocks, image display, image pickers
  • Ranking — drag-and-drop ranking of items

All fields include example defaultValue data so you can immediately see how values are stored and submitted.
