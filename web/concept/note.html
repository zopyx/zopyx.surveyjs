What is Privacy Forms Studio?

  • a SurveyJS-based solution for creating forms and surveys
  • Privacy first
  • Secure Data Collection
  • Drag-and-Drop Form Creation

Features

  • modern web forms and web surveys
  • Processing of form/survey data:
  • Storage
  • all form data can be stored (default)
  • or processed and distributed immediately
  • Transformation
  • Submitted form/survey data can be converted to various formats:
  • TXT
  • HTML
  • PDF
  • Markdown
  • JSON
  • Excel
  • CSV
  • DOCX
  • XML
  • Distribution
  • Each form submission can be sent/distributed by email in any of the configurable formats. The email configuration is per-form (individual recipients, CC: and BCC: support, individual subjects are per form)
  • Each form submission can be sent to an arbitrary REST endpoint using HTTP POST
  • AI support
  • AI support is optional
  • works with almost any AI provider (usually requires a related API key)
  • can be attached to any local LLM (privacy)
  • can be used to draft new forms or new surveys using natural language
  • can be used to refine or change existing forms
  • supports most languages supported by the underlying LLM/AI provider
  • Form versioning
  • Privacy Forms Studio keeps copies of previous form versions. You preview and older form version and, if necessary, restore an older version
  • Data portability
  • Your data and form definitions are stored by default within the Plone database.
  • Data and form definitions are stored as JSON and can be exported easily through the Privacy Form Studio UI
  • Integration with existing business solutions
  • Data from other data sources can be used, e.g. for drop-down fields if there is a related REST endpoint exposing the required data
  • Data collected from a form can be pushed into backend systems for further processing using the HTTP POST integration (per form)
  • Open to custom processing
  • Custom integrations for processing and/or distributing the data could be implemented in Python. Submitted form data can be sent to subscribers for arbitrary processing and handling.
  • Power of Plone
  • Management of forms/surveys can be delegated within your organisation
  • Forms/Surveys can be published/retracted in general, or the publication of a survey can be scheduled for a given time frame (e.g. a survey being open for a week or so)
  • Transparent, auditable, long-term sustainable—no black boxes, no forced cloud dependencies.
  • Shared privacy-first philosophy
  • Both are designed for full self-hosting, data sovereignty, and strict GDPR/DSGVO compliance.
  • Separation of concerns done right
  • SurveyJS handles dynamic form logic and UX, while Plone provides robust content, workflows, permissions, and governance.
  • Ideal for regulated environments
  • Perfect fit for public sector, healthcare, research, education, and enterprise use cases where SaaS form builders are not acceptable.
  • JSON meets structured content
  • SurveyJS’s JSON schemas integrate cleanly with Plone’s content types, workflows, and APIs.
  • Enterprise-grade extensibility
  • Both platforms are highly extensible without vendor lock-in—custom logic, validation, workflows, and integrations stay fully under your control.
  • Modern UX on a trusted CMS
  • SurveyJS delivers rich, dynamic form experiences inside Plone without compromising security or editorial control.
  • Future-proof architecture
  • Works seamlessly with modern frontends (REST, GraphQL, headless setups) while keeping Plone as the authoritative backend.

Privacy

  • Privacy-first architecture
  • The platform is designed from the ground up with privacy and data sovereignty as core principles—not as add-ons.
  • Full control over your data
  • All submitted form and survey data is processed within your own infrastructure and, by default, stored only on your servers.
  • No hidden data flows
  • No form or survey data is transmitted to external services unless you explicitly enable and configure such integrations.
  • Optional and controlled AI assistance
  • AI-supported form creation is entirely optional. You may use your own large language model or a privacy-focused LLM deployment, ensuring that no sensitive data leaves your trusted environment.
  • Configurable privacy levels
  • You decide how data is processed, stored, retained, or deleted. The level of privacy and compliance is fully configurable and remains under your control at all times.

Why SurveyJS?

Key Features (Inspired by SurveyJS)

  • JSON-based, fully configurable forms and surveys
  • Powerful conditional logic, validation, and calculated fields
  • Rich set of question types and repeatable form sections
  • Responsive, accessible UI for desktop and mobile
  • Multi-language support and localization
  • Visual form builder for fast authoring, plus code-level control
  • Easy embedding into existing web applications
  • Framework support for React, Vue, Angular, and vanilla JS
  • Structured JSON data output and prefilled form states

Why SurveyJS-style Architecture (Privacy-First)

  • No mandatory SaaS backend – forms run entirely in your own infrastructure
  • Full data sovereignty – all responses stay under your control
  • No hidden telemetry or third-party tracking
  • Ideal for GDPR / DSGVO-critical use cases (health, legal, HR, public sector)
  • Clear separation between form logic and data storage, unlike many hosted form builders
In contrast to many hosted survey platforms, this approach avoids vendor lock-in, uncontrolled data transfers, and opaque data processing—making it especially suitable for privacy-sensitive and regulated environments.
