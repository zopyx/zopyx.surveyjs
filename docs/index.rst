=====================
Privacy Forms Studio
=====================

Welcome to the documentation for the SurveyJS integration for Plone.

This documentation serves two audiences: integrators who install and operate
the system, and end users who build and run surveys in the UI.

Project links
-------------

   :class: project-links
   :widths: 25 25 25 25

   * - `Try the demo <https://demo.privacyforms.studio>`_
       Explore Privacy Forms Studio in a running instance.
     - `Read the docs <https://docs.privacyforms.studio>`_

     - `View on GitHub <https://github.com/zopyx/zopyx.surveyjs>`_
