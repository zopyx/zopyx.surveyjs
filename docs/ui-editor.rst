Editor
======

Open the survey and start the **editor** (``@@editor``): the SurveyJS
Creator lets you drag question types onto the page, configure validation
and logic, and preview the result — everything is saved as JSON
automatically, and every save creates a new form version (see
:doc:`survey-options` for the settings).
